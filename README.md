# الوجوه: لغةٌ مات قارئوها — Faces: An Unread Language

موقع ثابت ثنائي اللغة (عربي + إنجليزي): صور لوجوه ناسٍ التقاهم ماجد الأهدل في مكة بين 2016 و2018، ونصوص كتبها بصوتهم أو عنهم، مع ترجمة إنجليزية. 46 وجهًا بترتيبها الزمني. الاسم من عبارة كتبها تحت أحد وجوه سلسلة «Proletarian» عام 2016: «في وجوه الكادحين لغةٌ مات قارئوها في حادث اصطدامٍ شنيعٍ مع الرفاه». (اسم المستودع `wujuh-al-aysh` قديم ولم يُغيَّر.)

## التشغيل

```bash
python3 build.py              # يبني الموقع كله في dist/
python3 -m http.server 8765 --directory dist   # معاينة محلية: http://localhost:8765
```

يحتاج Python 3 ومكتبة Pillow فقط. لا شيء يُحمَّل من الإنترنت (الخطوط والصور محلية).

## بنية المشروع

| المسار | وظيفته |
|---|---|
| `data/faces.json` | بيانات الوجوه والنص العربي (مولَّدة، لكن يمكن تعديلها يدويًا) |
| `data/en/p1.py … p5.py` | الترجمة الإنجليزية وملاحظات المترجم لكل وجه (مفتاحها رقم الوجه `"01"`…) |
| `images/NN.jpg` | الصور الأصلية بحجم إنستغرام (1080px) |
| `site/` | CSS وJS والخطوط |
| `build.py` | يولّد الصفحات والمصغّرات وصورة المشاركة |
| `tools/extract.py` | استخراج أصلي من أرشيف إنستغرام (يعتمد مسارات على جهازك؛ لا حاجة له بعد الاستخراج) |
| `dist/` | الموقع الجاهز للرفع |

## التعديلات الشائعة

- **تصحيح نص عربي:** عدّل الحقل `text_ar` في `data/faces.json` ثم `python3 build.py`. (تنبيه: إعادة تشغيل `tools/extract.py` تكتب فوق `faces.json`.)
- **تصحيح ترجمة:** عدّل الوجه المقصود في `data/en/p*.py`.
- **حذف وجه:** احذفه من `faces.json` ومن ملف الترجمة، ثم أعد البناء. الترقيم يُعاد تلقائيًا من الترتيب الزمني، لكن اسم ملف الصورة `images/NN.jpg` يتبع الرقم القديم؛ لذا الأيسر إعادة تشغيل `tools/extract.py` بعد حذف السطر من `SEL`.
- **تحريك نقطة تركيز مصغّرة:** في `build.py` القاموس `FOCUS` (مثلًا `"46": (0.5, 0.6)` = x، y من 0 إلى 1).
- **الأصل (الفلتر):** الحقلان `origin_ar/origin_en` في `faces.json`، والتجميع في `GROUPS` بأعلى `build.py`.
- **نصّ الصفحة الرئيسية و«عن المشروع»:** داخل `build.py` (دالتا `page_index` و`page_about`).

## النشر

المجلد `dist/` موقع ثابت كامل؛ يصلح للرفع كما هو على GitHub Pages أو Netlify أو Cloudflare Pages أو أي استضافة ملفات. الروابط نسبية فيعمل من أي مسار فرعي. فيه `.nojekyll` لـ GitHub Pages.

## ملاحظات

- **الخطوط:** Thmanyah (Serif Display / Serif Text / Sans) منقولة من مشروع المدونة؛ راجع شروط ترخيصها إن استضفتَ الموقع في مكان آخر.
- **الوضع الداكن:** تلقائي حسب إعداد الجهاز.
- **التنقل:** على صفحة الوجه، السهم الأيسر = التالي، والأيمن = السابق (الصفحة عربية).
- **المنشورات المؤرشفة:** ثمانية من الوجوه (رقم 1 و2 و3 و35–39) كانت مؤرشفة (مخفية) على إنستغرام ولم تكن في `posts.json`؛ استُخرجت من ملف التصدير `archived_posts.html`. إن رأيتَ إبقاءها مخفية فاحذفها.

- **وجه 2015 محذوف:** كان أول وجه (عمّال سوقَي الغنم والخضار، 29 أغسطس 2015) فحذفه ماجد؛ فصار المدى 2016–2018.
